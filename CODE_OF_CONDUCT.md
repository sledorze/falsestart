# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, and keep discussion about the work. Harassment of any
kind is not tolerated.

Report unacceptable behaviour to the maintainer through
[GitHub](https://github.com/sledorze/falsestart/issues) for anything public, or a
[private security advisory](https://github.com/sledorze/falsestart/security/advisories/new) for
anything that should not be.
